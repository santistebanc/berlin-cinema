# First-party Berlin screening sources: venues, chains and ticketing platforms

All pages, endpoints and robots files below were observed on **16 October 2026** with a handful of requests per site. "Project data" means OV Berlin's own `public/movies.json` (berlin.de + critic.de, observed 2026-10-16T04:00Z, covering 2026-10-16 to 2026-10-22). Aggregators/portals/open data are covered in a separate note; commercial feeds are in `licensed-feeds.md`.

## Which ticketing platforms power Berlin cinemas, and can one adapter cover many venues?

### Takeaway
kinoheld is the dominant independent platform (about 20 venues and open-air sites, counting Sputnik and City Kino Wedding, which book through kinoheld widgets), but none of its machine endpoints is open to automated clients. Its robots rules exclude `/ajax/`, the whole `api.kinoheld.de` host and AI agents by name. The leverage is one level up: several venues share a **site template**, and those templates render the kinoheld/cinetixx data server-side. Three groups follow this pattern: the WordPress multisite behind Moviemento/Central/Toni, the Hackesche Höfe TYPO3 template and the Tilsiter-group PDF. cinetixx and kinotickets.express are also closed (robots `Disallow: /`). Chains use Vista, but each exposes it through its own front-end.

### Cited Findings
- **kinoheld:** [robots.txt](https://www.kinoheld.de/robots.txt) disallows `/ajax/`, `/payment/`, `/user/` for all agents. It blocks GPTBot, ClaudeBot, CCBot and other AI crawlers entirely. A venue page ([IL KINO on kinoheld](https://www.kinoheld.de/kino/berlin/il-kino/vorstellungen)) is a Nuxt app. Its payload configures a GraphQL client at `https://next-live.kinoheld.de/graphql` with a Bearer token stored in a cookie, and the server payload contained no show/version strings. [api.kinoheld.de/robots.txt](https://api.kinoheld.de/robots.txt) is `Disallow: /`. Wolf's own bundle calls `https://api.kinoheld.de/app/v2/shows` from the browser with cinema id `1856` ([Wolf kinoheld.js](https://wolfberlin.org/assets/builds/kinoheld.js?v=19cad189)). No public kinoheld API documentation was found; the only search hit was a third-party vendor case study ([International Showtimes](https://www.internationalshowtimes.com/use-cases/case-study-5)).
- **kinoheld data shape (via a venue proxy):** Filmrausch republishes kinoheld data at [`/wp-json/filmrausch/v1/programm?lang=de`](https://www.filmrausch.de/wp-json/filmrausch/v1/programm?lang=de). It contains `shows[]` with `id`, `cinemaId`, `beginning.isoFull` (correct offset), `flags[{category:"language", name:"OmeU"|"OmdU"|"OV", code}]`, `subtitle`, `auditoriumId`, and `movies{…title, title_orig…}`. The 40 shows run from 2026-10-16 to 2026-11-04.
- **kinoheld embed styles seen:** (a) a server-rendered list with `kinoheld.de/…/vorstellung/{id}` links ([Moviemento](https://moviemento.de/), [Krokodil](https://kino-krokodil.de/programm/), [Il Kino](https://www.ilkino.de/)); (b) widget links with `data-showid` ([Hackesche Höfe](https://www.hoefekino.de/)); (c) the client-side "eframe" `kinoheld.de/dist/eframe/eframe.min.js` with `period: 'today'` ([b-ware!](https://www.ladenkino.de/), [Intimes](http://kino-intimes.de/), [Tilsiter](http://tilsiter-lichtspiele.de/), [Zukunft](http://kino-zukunft.de/), [Stralau](https://freiluftkino-stralau.de/)); (d) a widget behind the venue's own ticket page ([Sputnik ticket page](https://www.sputnik-kino.com/film/56674) → kinoheld `mode=widget&showId=…`; [City Kino Wedding](https://www.citykinowedding.de/) `tickets.php?id=` → kinoheld eframe).
- **cinetixx:** [api.cinetixx.de/robots.txt](https://api.cinetixx.de/robots.txt) answers with a 302 to `/Access` and the body `User-agent: * Disallow: /`. [booking.cinetixx.de/robots.txt](https://booking.cinetixx.de/robots.txt) only disallows voucher paths. Venues link `booking.cinetixx.de/frontend/index.html?cinemaId=…&showId=…` with these IDs: [Acud](https://www.acudkino.de/) `1627459203`, [Transtopia](https://sinematranstopia.com/de) `2317182724`, [Zeughauskino](https://www.dhm.de/zeughauskino/) `1836256128`, [fsk](https://fsk-kino.peripherfilm.de/) `2278359999`.
- **kinotickets.express:** [robots.txt](https://kinotickets.express/robots.txt) is `Disallow: /`. Arsenal's API `salesUrl` values point to `kinotickets.express/arsenal-berlin/booking/{n}` ([Arsenal API](https://www.arsenal-berlin.de/api/v1/search/calendar/)). The [shop footer](https://kinotickets.express/arsenal-berlin) links to kinotickets-online.com and marsedv.de.
- **Vista:** CineStar's cinema list states `"ticketing":"vista"` with `ticketingLink` `https://webticketing3.cinestar.de/?cinemaId=46776&movieSessionId=%SYSTEM_SESSION_ID%` ([CineStar API](https://www.cinestar.de/api/cinema/)). Yorck film records carry `vistaId` (e.g. `HO00006029`), and its app bundle calls Vista `RESTBooking.svc` / `RESTTicketing.svc` through an AWS API Gateway proxy ([Yorck film page data](https://www.yorck.de/filme/sinn-und-sinnlichkeit-2026); [Yorck app bundle](https://www.yorck.de/_next/static/chunks/pages/_app-50179f7fd87732f5.js)).
- **Template sharing:** Moviemento, Central and Toni serve uploads from `wp-content/uploads/sites/3`, `/4` and `/9` and use identical programme markup ([Moviemento](https://moviemento.de/), [Central](https://kino-central.de/), [Toni](https://kino-toni.de/)). Moviemento's menu also links Open Air Kino Mitte at [kino-central.de/openair](https://kino-central.de/openair/). Freiluftkino Hasenheide's navigation includes "Unser Hackesche Höfe Kino", and it uses the same `programme-table-main` classes ([Hasenheide](https://www.freiluftkino-hasenheide.de/)). One weekly PDF covers "Tilsiter Lichtspiele · Kino Intimes · Kino Zukunft" ([Kinowoche 42](http://tilsiter-lichtspiele.de/Kinowoche-42-2026.pdf)).

### Inferences
- kinoheld and cinetixx appear to share one ID space or backend. fsk's cinetixx link uses movie id `3648335521` ([fsk](https://fsk-kino.peripherfilm.de/)), and Filmrausch's kinoheld data uses the same `showGroupMovieId` `3648335521` for *London* ([Filmrausch JSON](https://www.filmrausch.de/wp-json/filmrausch/v1/programm?lang=de)). Sputnik and City Kino Wedding use cinetixx images but kinoheld booking. A future licensed kinoheld/cinetixx feed could therefore cover about two dozen Berlin venues. That would be the best single partnership request.
- With robots excluding kinoheld's `/ajax/`, `api.kinoheld.de` and `api.cinetixx.de`, scraping those hosts is not defensible without written permission, even where a client-side key is visible in a venue bundle.
- CinemaxX and CineStar are both owned by Vue; the German competition authority cleared their merger in 2020 ([Concurrences](https://www.concurrences.com/en/bulletin/news-issues/march-2020/the-german-competition-authority-clears-a-merger-between-cinema-chains-subject)). They still expose different front-end APIs, so they need separate adapters.

### Gaps
- kinoheld's eframe script, GraphQL schema and terms were deliberately not fetched or queried after its robots file was read. Its ToS on data reuse and whether it offers a partner feed are unverified.
- The platform behind UCI's `buchung.uci-kinowelt.de` (`perf_id` parameter) could not be identified because it serves a Cloudflare challenge ([booking link](https://buchung.uci-kinowelt.de/?perf_id=05BF1000023ZIQERCX&site_id=82)).
- No Compeso, Ticket International, Admit-One, Eventim or Pretix booking links were found on the Berlin venue pages checked. A `compeso` cookie-category string on [CineMotion](https://cinemotion-kino.de/) is not evidence of Compeso ticketing.

## How do the chains expose their programmes?

### Takeaway
Four of six chain front-ends expose clean, unauthenticated structured data: Yorck (`__NEXT_DATA__`), CineStar (JSON API), CinemaxX (JSON microservice) and premiumkino/Zoo Palast (JSON). UCI is parseable HTML with explicit OV tokens. Cineplex is blocked by Cloudflare. In the current 7-day window, OV session counts from these feeds are close to what berlin.de/critic.de already give. The main gains are a longer horizon, booking URLs, original titles/TMDB IDs and source redundancy, not new venues.

### Cited Findings

## Which independents publish machine-readable programmes?

### Takeaway
Six independents expose data that can be parsed without HTML heuristics: Arsenal (JSON API with explicit `languageVersion` and `filmFormat`), IL KINO (full schema.org `ScreeningEvent` graph), Filmrausch (JSON endpoint), Brotfabrik (The Events Calendar REST), Sputnik (microdata + RSS, short horizon) and Babylon Mitte (per-film JSON-LD, one show each). The big indie win is one parser for the Moviemento/Central/Toni multisite and one for the Hackesche Höfe template. Wolf, b-ware!, Intimes, Tilsiter and Zukunft render showtimes only client-side through kinoheld, or in PDFs.

### Cited Findings
- **Arsenal:** the [Kalender](https://www.arsenal-berlin.de/kalender/) page carries `data-endpoint="https://www.arsenal-berlin.de/api/v1/search/calendar/"`. That [endpoint](https://www.arsenal-berlin.de/api/v1/search/calendar/) returns Solr results, 12 per page, paged with `?tx_solr[page]=2` ([page 2](https://www.arsenal-berlin.de/api/v1/search/calendar/?tx_solr%5Bpage%5D=2)). The pages covered about 16–25 Oct.

## What should OV Berlin add next?

### Takeaway
Order by value per effort. (1) Arsenal JSON and IL KINO JSON-LD: small effort, best OV metadata, ask permission. (2) The Moviemento/Central/Toni parser: 4 programmes.
